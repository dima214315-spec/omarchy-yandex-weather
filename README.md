# Яндекс Погода для Omarchy

Виджет бара для [Omarchy](https://omarchy.org) (4 «Quattro»): текущая
температура; по клику — панель с прогнозом на 10 дней, разбором
по утро/день/вечер/ночь, списком городов, поиском и кнопкой определения
города по геолокации. Данные — с [Яндекс.Погоды](https://yandex.ru/pogoda).

## Установка

```bash
git clone https://github.com/polehome/omarchy-yandex-weather.git \
  ~/.config/omarchy/plugins/pole.yandex-weather
omarchy bar put pole.yandex-weather --section centerEnd
```

Без git: скачайте архив c GitHub и распакуйте в
`~/.config/omarchy/plugins/pole.yandex-weather/`, затем:

```bash
omarchy restart shell
omarchy bar put pole.yandex-weather --section centerEnd
```

Обновление: `git -C ~/.config/omarchy/plugins/pole.yandex-weather pull`,
затем `omarchy restart shell`.

## Как пользоваться

| Действие | Мышь | Клавиатура в панели |
|----------|------|---------------------|
| Открыть панель | клик по температуре в баре | — |
| Обновить | средняя кнопка на баре / стрелка у заголовка | `r` |
| Следующий/предыдущий город | колесо над баром | `n` / `p`, затем Enter |
| Выбрать день | клик по строке | ↑ ↓, ← → |
| Убрать город из списка | правый клик по городу | — |
| Поиск города | поле «Найти город…» | `/` или `f`, затем Enter |
| Определить город по IP | кнопка «Определить» | — |
| Закрыть | клик мимо | `Esc` |

Поиск понимает и русские, и английские названия («Москва», «Moscow»,
«спб», «Люберцы»). «Определить» берёт координаты по IP (ipinfo.io) и просит
Яндекс назвать город.

## Настройки (`~/.config/omarchy/shell.json`)

```jsonc
{
  "id": "pole.yandex-weather",
  "city": "elektrougli",      // slug города на yandex.ru/pogoda
  "cityName": "Электроугли",
  "cities": [ ... ],          // города для быстрого переключения
  "refreshMinutes": 30,       // 0 — обновлять только при открытии панели
  "showCondition": false,     // добавить в бар слово «ясно», «дождь»…
  "outerGap": 10              // отступ от соседних значков в баре, px
}
```

Город меняется прямо в панели и сохраняется в `shell.json`.

## Требования

- Omarchy 4 (Quickshell-шелл), Hyprland;
- `python3` в `PATH` (стандартный `python3` Arch);
- интернет: страницы `yandex.ru/pogoda` и `ipinfo.io` (только для «Определить»).

## Как это устроено

- `BarWidget.qml` — виджет бара: хранит последнее удачное чтение, раз в
  `refreshMinutes` минут берёт новые данные, держит панель и пишет выбранный
  город в `shell.json`.
- `Panel.qml` — всплывающая панель: текущая погода, поиск, города, прогноз
  на 10 дней, разбор по частям суток. Крупный шрифт, шкала в одном месте
  (`text()` над токенами `Style.font.*`).
- `WeatherIcon.qml`, `WeatherIcons.js` — значки погоды: контуры Lucide и
  Fluent (ISC/MIT) вставляются как SVG в RichText и красятся цветом темы.
- `bin/yandex-weather.py` — сеть и разбор страницы Яндекса:
  `weather <slug>`, `search <запрос>`, `locate`, `validate <ссылка>`.
- `i18n/` — тексты панели (русский и английский), следуют языку Omarchy.
- `icons/` — превью значков и лицензии.
- `docs/устройство.md` — подробности реализации и известные ограничения.

Проверить данные без интерфейса:

```bash
python3 ~/.config/omarchy/plugins/pole.yandex-weather/bin/yandex-weather.py weather moscow | python3 -m json.tool | head
```

## Ограничения

- Бар рисует подпись плагина шрифтом бара и с шириной по своему расчёту,
  поэтому в баре показывается температура, а значок погоды живёт в панели и
  в подсказке при наведении. Значок в баре упирается в особенности
  нынешнего слотового контейнера шелла (подпись плагина измеряется, но
  рисуется от начала своего бокса), и попытка его добавить наезжает на
  соседний виджет.
- Геолокация — по IP: город будет не точнее провайдера (может отличаться от
  фактического на несколько километров или быть соседним городом).
- Данные берутся с публичной страницы Яндекс.Погоды, а не через официальный
  API: если Яндекс изменит разметку, скрипт придётся поправить.

# Иконки погоды

Панель и бар рисуют погоду линиями, а не картинками из файлов: контуры
лежат прямо в `WeatherIcons.js` (объект `SHAPES`), а `WeatherIcon.qml`
вставляет нужный контур в `Text` в режиме RichText и красит его цветом
темы. Так значок не зависит от того, из какой папки загрузили плагин
(бар берёт виджет из каталога плагина), масштабируется без потерь и
всегда рисуется.

## Откуда контуры

| Файлы | Источник | Лицензия |
|-------|----------|----------|
| `sun`, `moon`, `cloud`, `cloud-rain`, `cloud-rain-wind`, `cloud-drizzle`, `cloud-snow`, `snowflake`, `sun-snow`, `cloud-lightning`, `cloud-hail`, `cloud-fog`, `wind` | [Lucide](https://lucide.dev) (`lucide-icons/lucide`, каталог `icons/`) | ISC, см. `LICENSE-lucide` |
| `fluent-partly-cloudy-day`, `fluent-partly-cloudy-night` | [Microsoft Fluent UI System Icons](https://github.com/microsoft/fluentui-system-icons), `assets/Weather Partly Cloudy Day|Night/SVG/..._48_filled.svg` | MIT, см. `LICENSE-fluent` |

Цвет контура задаётся при отрисовке: светлый (`#E4EDE9`) для текущего
состояния и наведения, приглушённый (`#6E8280`) для остальных строк.

## Какие иконки под какой вид погоды

`bin/yandex-weather.py` переводит подпись со страницы Яндекса (или код из
его JSON) в *вид* погоды, а `WeatherIcons.js` — в контур:

| Вид (`kind`) | Контур днём | Контур ночью |
|--------------|-------------|--------------|
| `clear` — ясно, солнечно | солнце | луна |
| `mostly` — малооблачно, облачно с прояснениями | солнце за облаком | луна за облаком |
| `overcast` — пасмурно, облачно | облако | облако |
| `rain` — дождь, ливень | облако с каплями | облако с каплями |
| `showers` — дождь с ветром | облако с каплями на ветру | — |
| `drizzle` — небольшой дождь, изморось | облако с мелким дождём | — |
| `snow` — снег, метель, крупный снег | облако со снегом | — |
| `snowflakes` — снежинки | снежинка | — |
| `sleet` — дождь со снегом | солнце со снегом | облако со снегом |
| `thunder` — гроза | облако с молнией | — |
| `hail` — град | облако с градом | — |
| `fog` — туман, дымка | облако с полосами | — |
| `wind` — ветер, буря, шквал | ветер | — |
| `unknown` — ничего не разобрали | облако | — |

Рядом с иконкой всегда стоит подпись самого Яндекса («ясно», «дождь со
снегом», …), так что иконка — иллюстрация, а не источник истины.

## Превью

`preview.png` — все контуры подряд на фоне темы; `preview-dim.png` — они же
в приглушённом тоне. Остальные PNG — те же контуры по отдельности, включая
ночные варианты. Ни один из них виджет не открывает: рисунок собирается из
контура на лету. Это справочные картинки для тех, кто правит набор.

## Если нужен новый вид

Добавьте контур в `SHAPES` в `WeatherIcons.js`, строку в `OUTLINE` и, если
у вида есть ночная версия, строку `"<вид>-night"`. Если подпись Яндекса
изменится, достаточно дополнить `KIND_WORDS` в `bin/yandex-weather.py`:
скрипт ищет слова («дожд», «снег», «гроз», …), а не фразы целиком.
